# AI名言生成モーダルUIの実装計画

## 目標
名言生成機能のUIを、より直感的で楽しい「チャット風モーダル」に改修します。生成された名言を確認してから、登録フォームへ反映するかどうかをユーザーが選べるようにします。

## 提案する変更内容

### 1. モーダルUIの導入 (`src/app/quotes/register/page.tsx`)
*   「使ってみる」ボタンを押した際に、インラインでフォームを展開するのではなく、画面中央にモーダルダイアログを表示する形式に変更。

### 2. チャット形式の表示
*   **ステップ 1**: 有名人やテーマを入力するフォームと送信ボタンをモーダル内に設置。
*   **ステップ 2**: 送信すると、「ユーザーの入力内容（右側吹き出し）」がチャット画面に表示。
*   **ステップ 3**: AIの生成中アニメーション（ローディングインジケーター）を表示。
*   **ステップ 4**: AIからの返答として「生成された名言（左側吹き出し）」が表示される。

### 3. 反映機能
*   AIの返答メッセージ内に「この名言を使用する」というアクションボタンを追加。
*   クリックするとモーダルが閉じ、メインページの名言・著者入力欄に生成内容がセットされる。
