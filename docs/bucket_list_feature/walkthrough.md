# バケットリスト機能 検証手順

## 実装内容
- **データ管理**: `localStorage` を使用して「死ぬまでにやりたいことリスト」を保存。
- **UI**:
    - リストの追加フォーム
    - 未完了/完了の状態切り替え（チェックボックス）
    - 削除機能（ゴミ箱アイコン）
    - レスポンシブ対応のデザイン
- **ナビゲーション**: ヘッダーに「やりたいこと」リンクを追加。

## 検証ステップ

1.  **アクセス確認**
    - [ ] アプリを起動し、ヘッダーに「やりたいこと」というリンクが表示されていることを確認。
    - [ ] リンクをクリックし、`/bucket-list` に遷移することを確認。

2.  **アイテム追加**
    - [ ] 入力フォームに「スカイダイビングをする」などと入力し、＋ボタン（またはEnterキー）を押す。
    - [ ] リストの一番上にアイテムが追加されることを確認。
    - [ ] 入力フォームが空になることを確認。

3.  **状態切り替え**
    - [ ] 追加したアイテムの左側の丸アイコンをクリック。
    - [ ] チェックマークが付き、テキストに取り消し線が入ることを確認。
    - [ ] もう一度クリックして、元に戻ることを確認。

4.  **削除機能**
    - [ ] アイテムの右側にあるゴミ箱アイコンをクリック（PCではホバー時に表示）。
    - [ ] 確認ダイアログが表示されることを確認。
    - [ ] 「OK」を押すとリストから消えることを確認。

5.  **データ永続化**
    - [ ] いくつかアイテムを追加した状態でページをリロード。
    - [ ] 追加したアイテムがそのまま残っていることを確認。

6.  **レスポンシブ確認**
    - [ ] ブラウザの幅を狭めて（スマホサイズ）、レイアウトが崩れないことを確認。
