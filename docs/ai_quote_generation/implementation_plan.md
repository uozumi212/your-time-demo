# AI名言生成機能の実装計画

AIを利用して、著名人やキャラクターの名言を自動生成・入力する機能を追加します。

## User Review Required

> [!IMPORTANT]
> **利用するAIのAPIについて**
> 以下からお好みのAPI方針を選択、またはご指定ください。
> 1. **Google Gemini API** (おすすめ: 無料枠があり、手軽に利用可能)
> 2. **OpenAI API** (精度の高い生成が可能ですが、有料のAPIキーが必要)
> 3. **Chrome Built-in AI** (`window.ai`): 試験的なブラウザ内蔵AI (APIキー不要ですが、Chromeの設定が必要です)
>
> 1または2の外部APIを利用する場合は、APIキーを `.env.local` に設定する想定で実装を進めます。どちらのAPIを利用したいか教えていただけますでしょうか？（例：「Gemini APIを使いたい」「OpenAIで実装して」など）

## Proposed Changes

### フロントエンド (`src/app/quotes/register/page.tsx`)
*   **UI追加:**
    *   フォーム上部に「AIで名言を生成する」ボタンを追加。
    *   クリックで「テーマや人物名（例：スティーブ・ジョブズ、ナルト）」を入力するシンプルなダイアログ（またはインラインフィールド）を表示。
*   **ロジック追加:**
    *   入力されたテーマをバックエンドAPIに送信。
    *   レスポンスとして受け取った「名言(`quote`)」と「著者(`author`)」を、既存のフォームのステートに自動でセット。

### バックエンド APIルート (例: `src/app/api/generate-quote/route.ts`)
*   **APIエンドポイント構築:** [NEW]
    *   フロントからのリクエストを受け取り、プロンプトを構築してAI(例: Gemini/OpenAI)に送信。
    *   JSON形式（`{ "quote": "...", "author": "..." }`）でフロントに返却する処理を実装。

## Verification Plan

### Manual Verification
1. 開発サーバーを起動し、名言登録ページ (`/quotes/register`) にアクセス。
2. 「AIで生成」ボタンをクリックし、人物名（例：「アインシュタイン」）を入力して生成を実行。
3. ローディング表示後、名言と著者がフォーム枠に自動入力されることを確認。
4. そのまま「登録する」ボタンを押し、正しく一覧に登録されるか確認。
